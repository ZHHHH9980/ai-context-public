# AI Context Public

## 定位

这是一个面向 AI 的公开上下文仓库，用于存放脱敏后的可公开知识和决策记录。

## 核心原则

- **禁止放敏感信息**：不包含 token、密码、内部账号、私有路径等
- **脱敏重写**：所有内容从私有笔记中筛选并重写后放入
- **稳定引用**：提供可复用的上下文链接，供不同 AI/会话使用
- **降低重复成本**：减少每次重复解释背景的开销

## 仓库结构

```
ai-context-public/
├── README.md          # 本文件，仓库说明
├── INDEX.md           # 内容索引
├── context/           # 完整上下文文档
├── docs/              # 主题文档（按项目/领域组织）
├── faq/               # 常见问题解答
└── decisions/         # 关键决策记录
```

## 使用方式

1. **喂给 AI**：直接将相关文档链接或内容提供给 AI
2. **协作复用**：团队成员可引用同一套知识库
3. **版本追踪**：通过 Git 历史追踪知识演进

## 内容来源

本仓库内容来自私有笔记仓库的筛选和脱敏重写，不是自动同步，而是人工维护的单向映射。

## 安全提示

- 提交前务必检查是否包含敏感信息
- 启用 GitHub 2FA
- 定期审查仓库内容
